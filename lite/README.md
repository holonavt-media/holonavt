# Лёгкие копии медиа (12.10.2026)

Оригиналы в корне хранилища НЕ тронуты. Имена файлов совпадают с оригиналами.

- tiles/ — WebP 448 px по ширине (плитки Энциклопедии), качество 80
- cards/ — WebP 600 px по ширине (карточка Тотема), качество 82
- video/ — те же MP4, пережатые H.264 (CRF 27, без звука, быстрый старт)

Было: картинки 108,8 МБ, видео 270 МБ. Стало: tiles 7,8 МБ, cards 14 МБ, video 110 МБ.
PDF-книга продолжает брать оригиналы.

## 3D (14.10.2026)

- models/man.glb, models/woman.glb — облегчённые фигуры для 3D: только форма тела
  (без встроенной текстуры, UV и тангент), координаты сжаты (KHR_mesh_quantization,
  three.js r128 читает без декодеров). Было 7,5 + 3,3 МБ, стало 0,96 + 1,41 МБ.
  Оригиналы man.glb и woman.glb в корне не тронуты.
- textures/earth-night.jpg — ночная Земля 2048×1024 (135 КБ) для глобуса Anima Mundi
  и Земли в Колесе Года. Полный размер 4096×2048 — в папке textures/ в корне.
  Источник: проект three-globe (MIT, © Vasco Asturiano), снимок NASA Black Marble.
  Раньше 3D брал её прямо с чужого GitHub — теперь своя копия.
